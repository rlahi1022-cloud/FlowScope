FlowScope
📌 프로젝트 개요
FlowScope는 서로 다른 서버 아키텍처 4가지를 구현하고, 각 구조의 요청 처리 흐름을 실시간으로 시각화하여 비교할 수 있도록 만든 프로젝트입니다.

## 🚀 주요 기능

- **다양한 서버 아키텍처 구현**: 4가지 다른 아키텍처 패턴 제공
- **실시간 시각화**: 요청 처리 흐름을 실시간으로 시각화
- **성능 비교**: 각 아키텍처의 요청 처리 흐름 비교 가능
- **epoll 기반**: 고성능 이벤트 기반 아키텍처 포함
